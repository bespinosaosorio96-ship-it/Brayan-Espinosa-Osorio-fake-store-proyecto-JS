# FakeStore - Carrito de Compras (JavaScript)

## Descripción
Aplicación web que consume productos desde https://fakestoreapi.com/products y los muestra dinámicamente en el DOM.  
Incluye carrito de compras con persistencia en localStorage, búsqueda, filtros y ordenamientos.

## Funcionalidades
- Consumo de API con fetch (async/await).
- Renderizado dinámico de productos (tarjetas).
- Carrito: agregar, eliminar, total y contador.
- Persistencia del carrito con localStorage.
- Búsqueda por nombre o descripción.
- Filtro por categoría.
- Ordenamiento por precio y nombre.
- Diseño responsive (móvil, tablet, escritorio).
